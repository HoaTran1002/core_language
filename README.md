# Core Language

Kho nay duoc to chuc theo 2 truc chinh:
- `knowledge`: kien thuc nen tang, concept, pattern, syntax, example hoc tap.
- `technical`: ky thuat thuc hanh, benchmark, tooling, performance, troubleshooting, operational topic.

## Lop tai lieu chung

- `docs/core-concepts`: nhung concept chung co the doi chieu giua Java, Node.js va Python.
- `docs/knowledge-common`: nhung nhom kien thuc chung khi hoc bat ky ngon ngu nao.
- `docs/technical-common`: nhung ky thuat chung trong qua trinh xay dung va van hanh phan mem.
- `docs/official-sources`: danh sach link tai lieu chinh thong de bat dau hoc va tra cuu.

## Theo tung ngon ngu

- `java/`: core concepts, knowledge, technical chung va technical dac thu cua he sinh thai Java/JVM.
- `nodejs/`: runtime Node.js, JavaScript/TypeScript, technical chung va technical dac thu cua event loop.
- `python/`: core knowledge, technical chung va technical dac thu cua CPython/Python ecosystem.

## Cach doc repo

1. Doc `docs/` de nam khung chung va nguon tai lieu chinh thong.
2. Chon ngon ngu can hoc.
3. Vao `knowledge/` de hoc concept va nen tang ngon ngu.
4. Vao `technical/` de hoc tooling, testing, packaging, performance va van hanh.
5. Moi topic dac thu co `README.md` rieng va co link den nguon tai lieu chinh thong.
