# Node.js

## Muc tieu

Tai lieu cho Node.js duoc tach thanh `knowledge` va `technical`, trong do co phan chung cua JavaScript/TypeScript va phan dac thu cua runtime Node.js.

## Core concepts va knowledge

- `knowledge/runtime_basics`: process, runtime, globals, standard modules.
- `knowledge/event_loop_async`: event loop, callback, promise, async/await.
- `knowledge/modules_packages`: CommonJS, ESM, package, import/export.
- `knowledge/typescript`: typing, generics, utility types, ecosystem TypeScript.

## Technical chung

- `technical/package_tooling`: npm, script, dependency, versioning.
- `technical/testing_quality`: `node:test`, mocking, coverage awareness.
- `technical/benchmarking`: benchmark co ban cho workload CPU bound.

## Technical dac thu cua Node.js

- `technical/observability`: logging, process diagnostics, inspector, perf hooks.
- `technical/workers_scaling`: worker threads, child process, cluster awareness.
