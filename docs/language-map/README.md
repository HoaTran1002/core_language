# Doi Chieu Nhanh Giua Java, Node.js, Python

## Runtime model

- Java: JVM, thread-based concurrency, strong enterprise tooling.
- Node.js: single-threaded event loop cho main thread, mo rong bang workers/processes.
- Python: CPython runtime, expressiveness cao, nhieu lua chon concurrency tuy theo bai toan.

## Type system

- Java: static typing, generic typing, compiler-oriented design.
- Node.js: JavaScript dynamic typing, TypeScript them static layer tuy chon.
- Python: dynamic typing, type hints va static checking la tuy chon.

## Performance intuition

- Java: warmup va JIT rat quan trong.
- Node.js: manh o I/O bound, can workers cho CPU bound task.
- Python: phu thuoc nhieu vao algorithm, native extension, vectorization, multiprocessing.

## Packaging intuition

- Java: Maven/Gradle.
- Node.js: npm.
- Python: pip, venv, pyproject.toml, packaging guide.
