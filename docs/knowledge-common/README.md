# Knowledge Chung

## Muc tieu

Dinh nghia nhung nhom kien thuc nen hoc theo thu tu hop ly, bat ke dang hoc Java, Node.js hay Python.

## Nhung nhom kien thuc nen co

- Syntax va data model: variable, function, control flow, collection, object model.
- Type system: primitive type, object type, generic, optional type, inference.
- Modules va package: import/export, namespace, package layout.
- Error handling: exception, custom error, logging, validation.
- I/O basics: file, network, serialization, JSON.
- Concurrency basics: thread, async, queue, locking, cancellation.
- Standard library usage: collections, time, file system, process, HTTP support.

## Cach hoc

1. Hoc syntax va object model.
2. Hoc type system va module system.
3. Hoc I/O va error handling.
4. Hoc concurrency model cua ngon ngu.
5. Chuyen sang technical topics nhu testing, packaging, profiling.
