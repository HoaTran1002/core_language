# Technical Chung

## Muc tieu

Tong hop nhung ky thuat thuc hanh chung trong qua trinh xay dung, test, toi uu va van hanh phan mem.

## Nhung technical chung

- Build va dependency management.
- Testing va quality gate.
- Packaging va distribution.
- Configuration va environment management.
- Logging, metrics, tracing va observability.
- Profiling va performance tuning.
- Security basics: secret, dependency audit, update policy.
- CI/CD integration va automation.

## Cach ap dung

- Dung tai lieu chung nay de nhin ra topic tuong ung trong tung ngon ngu.
- Dung tai lieu dac thu cua ngon ngu de hieu su khac nhau ve cong cu va runtime.
