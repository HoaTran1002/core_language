# Core Concepts Chung

## Muc tieu

Tong hop nhung concept ma Java, Node.js va Python deu can nam, du ten goi va cach hien thuc co the khac nhau.

## Concept map

- Runtime model: process, thread, event loop, scheduler.
- Type system: dynamic typing, static typing, optional typing, generic typing.
- Memory model: stack, heap, object lifetime, garbage collection, resource cleanup.
- Error handling: exception, error propagation, retry, fail fast.
- Concurrency model: threads, async I/O, worker model, synchronization.
- Packaging model: dependency, module, package, versioning, distribution.
- Testing model: unit test, integration test, mocking, coverage.
- Performance model: CPU bound, I/O bound, latency, throughput, profiling.

## Doi chieu nhanh

- Java manh ve static typing, JVM, multithreading va tooling doanh nghiep.
- Node.js manh ve event loop, I/O bound workload, ecosystem package va web runtime.
- Python manh ve expressiveness, scripting, data ecosystem, optional typing va packaging linh hoat.
