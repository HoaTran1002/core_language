# Tai Lieu Chung

Bo tai lieu nay duoc to chuc theo 4 nhom chung:
- `core-concepts`: nhung y tuong cot loi xuyen suot nhieu ngon ngu.
- `knowledge-common`: nhung nhom kien thuc nen hoc o bat ky ngon ngu nao.
- `technical-common`: nhung ky thuat chung trong phat trien, kiem thu, toi uu va van hanh.
- `official-sources`: tap hop link tai lieu chinh thong.

## Nguyen tac to chuc

- Moi ngon ngu co 2 nhanh chinh: `knowledge` va `technical`.
- Moi nhom lon co `README.md` tong quan.
- Moi topic quan trong co thu muc rieng va `README.md` rieng.
- Link tai lieu uu tien tai lieu chinh thong cua ngon ngu, runtime, hoac tool.
