# Python

## Muc tieu

Tai lieu cho Python duoc tach thanh `knowledge` va `technical`, trong do co phan chung cua ngon ngu va phan dac thu cua ecosystem Python/CPython.

## Core concepts va knowledge

- `knowledge/syntax_basics`: syntax, data structures, functions, modules.
- `knowledge/data_model`: object model, dunder methods, iterator, context manager.
- `knowledge/typing`: type hints, generics, protocols, static checking awareness.
- `knowledge/oop`: class model, inheritance, dataclass, composition.
- `knowledge/async_io`: `asyncio`, coroutine, task, event loop.

## Technical chung

- `technical/packaging_environments`: `venv`, `pip`, `pyproject.toml`, packaging.
- `technical/testing_quality`: `unittest`, mocking, test discovery, quality basics.
- `technical/performance_profiling`: profiling, benchmark awareness, memory diagnostics.

## Technical dac thu cua Python

- `technical/runtime_concurrency`: GIL, multiprocessing, threading, async trade-off.
