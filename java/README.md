# Java

## Muc tieu

Tai lieu cho Java duoc tach thanh `knowledge` va `technical`, trong do co ca phan chung va phan dac thu cua Java/JVM.

## Core concepts va knowledge

- `knowledge/syntax_basics`: syntax, class, method, interface, enum, record.
- `knowledge/oop`: object model, encapsulation, inheritance, polymorphism.
- `knowledge/collections_generics`: collections framework va generic typing.
- `knowledge/memory_model`: stack, heap, reference, immutability, visibility.
- `knowledge/concurrency`: thread, lock, thread local, deadlock, starvation.

## Technical chung

- `technical/build_tooling`: Maven, Gradle, dependency va build lifecycle.
- `technical/testing_quality`: JUnit, assertions, test pyramid, code quality.
- `technical/benchmarking`: benchmark va do hieu nang co ban.

## Technical dac thu cua Java

- `technical/jvm_performance`: JIT, warmup, profiling, JFR, JMH awareness.
- `technical/garbage_collection`: GC model, collector, memory pressure, tuning can ban.
