# Java Concurrency

Tai lieu tong quan cho nhom `concurrency` trong Java.

## Topics

- `deadlock`: hai luong cho nhau giai phong tai nguyen.
- `livelock`: hai luong van hoat dong nhung khong tien duoc cong viec.
- `starvation`: mot luong bi thieu co hoi duoc cap phat tai nguyen.
- `thread_local`: du lieu rieng theo thread.
- `synchronized_wallet`: dong bo truy cap tai nguyen dung chung.
- `thread_pool_deadlock`: mo phong deadlock khi dung thread pool va lock.
